# v3.14.0 饮食弹窗与日期回顾

- 饮水记录区合为一个全宽按钮，右侧深灰加号仅作图标。轻微按压、数字过渡和两层持续水波提供反馈；点击的短暂波动自然衰减，水位不随次数升高。节点与循环动画保持不变，支持减少动态效果。
- 饮水写入按日期排队，快速连点及往返日期不丢计数；存储失败会恢复真实保存值并提示。保留最近一串点击的撤销功能。
- 食物说明以图标定位，修正毛玻璃弹窗造成的 fixed 坐标偏移，同时限制在弹窗和可视视口的交集内，随滚动、旋转和键盘视口变化重新定位。
- 添加食物与自定义食物共用底部弹窗、独立正文滚动区、顶部拖动条和固定操作栏。支持原生边界控制时不注册阻塞滚动的 touchmove；旧 WebView 仅在边界拦截。CSS 保留原生滚动与惯性，禁止滚动链和边界回弹。[CSS 边界行为参考](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/overscroll-behavior)。
- 自定义食物使用“食物名称”“常用分量单位”“每份克重/体积”；新建输入和分类为空，输入有外边框。能量继续支持 kcal/kJ 换算，g/ml 切换同步每 100 g/ml 营养口径，不在未知密度时换算质量与体积。保留食物 ID、修改和删除逻辑，历史饮食记录保留原营养快照。未填可选营养项及分量仍沿用原保存默认值。
- 今日页和添加食物的“今日进度”统一显示“碳水：脂肪”和“60：40”，移除条下参考文字；比例、参考带、指针和营养计算保持原逻辑。
- 当天继续提供实时提示和推荐入口；历史日期进入独立回顾分支，不读取当前时刻生成餐次建议。回顾显示记录摄入、营养与对照目标，说明目标按现有设置计算，缺记录不判为未进食。

验证使用独立浏览器数据目录，不接触真实账号数据：

```sh
node scripts/diet-interactions-smoke.mjs http://127.0.0.1:8137
BROWSER=webkit node scripts/diet-interactions-smoke.mjs http://127.0.0.1:8137
```

定向回归覆盖连续饮水、整串撤销、切日队列、保存失败、减少动态效果、空白表单、单位切换、后台刷新、编辑快照、320–430px 布局、横屏提示定位和历史回顾时间不变性。滚动回归检查长短正文顶部逐帧稳定、正常浏览、滚动到顶后不接管弹窗，以及拖动条关闭。

桌面 Chromium 的触摸模拟和 WebKit 自动化不能替代真实 iPhone 上的惯性手感验证；未用自制位移或减速曲线替代系统滚动。
