## 行为变化

1. 健身默认先看本次训练；选择动作成为独立弹层。近 7 日记录及部位间隔移到“训练记录”。组数编辑按动作展开，训练建议默认收起。
2. 列表、搜索和推荐都先加入待选；统一确认后保存并返回记组。选择过程中不刷新整页，不自动补下一批。已加入的动作不可在选择器重复添加。
3. 推荐数量现在是上限。已安排的模式占用对应位置，不用同模式变式补足 5/6 个。未做个体目标、时间和周组数求解，帮助文字明确这一限制。
4. 零组动作列在“已安排但未记组数”，不计为训练记录日。日期窗口、记录日、有效组及部位间隔使用一致口径；底层有效记录规则不变。
5. 删除按最新记录建立撤销快照，串行保存；撤销恢复本次删除，不覆盖后续新增。同 ID 冲突提示核对。有组数的清空及替换先确认，取消不写入；替换后新动作从空组开始，已有新记录时拒绝覆盖撤销。
6. 主按钮对比度改善；说明入口和次级文字按钮增加触控空间。200% 文字下建议按钮、器械标签允许换行，待选明细收在可展开清单中。
