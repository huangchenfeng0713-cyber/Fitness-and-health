# 今日点式指标

- 碳水/脂肪、膳食纤维、钠、游离糖默认仅显示名称、刻度、圆点与必要状态；蛋白质条仍显示原来的数值和目标。
- 点击轨道或圆点后，在圆点上方显示实际记录对应的读数，例如 `11 g`、`2039 mg`、`58 g`、`碳水 73% / 脂肪 27%`。碳水/脂肪第二行同时给出各自克数，例如 `碳水 182.5 g / 脂肪 30 g`。沿用原有取整规则，数字与单位之间按这次浮层设计保留空格。
- 浮层白底、圆角、轻阴影，箭头对准圆点；横向位置限制在主卡内。当前圆点轻微放大并显示高亮外圈，保留原来的状态颜色。
- 同时只显示一个读数。再次点击当前轨道、点击空白处或按 Escape 关闭；点击另一条轨道直接切换。键盘 Enter/空格均可打开。
- 滚动时保持打开时的屏幕坐标；调整窗口大小时重新避让。时钟或同步重绘同一天的卡片时保留浮层；离开页面或切换日期时清理。
- 无碳水/脂肪记录时保留原有「还没有记录」，不生成虚假的比例或圆点。

回归：`node scripts/today-metric-values-smoke.mjs http://127.0.0.1:8137`；可用 `BROWSER=webkit` 验证 WebKit，用 `ARTIFACT_DIR` 输出截图。
