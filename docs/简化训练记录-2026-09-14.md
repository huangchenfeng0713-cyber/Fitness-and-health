# 简化训练记录与七日概览（v3.21.0）

用户要求按已审查方案全部实施并合并。基于 main `6428a2ecb54d02addd235530425ae04cb66adccc`。

## 交互

- 移除今日页体重卡、数据页记体重按钮和手动补录体重字段。健康同步、体重趋势和档案无同步值时的兜底保留。
- 每个动作统一选择按次数/时长、负重方式、重量口径；设置沿用到下次，旧组不会被改写。组表只显示主要输入；草稿确认才落库，可批量确认相同的多组。新组默认正式组，热身单独标记，RIR 旧值保留但移出普通编辑器。
- 训练建议直接展开，解释集中在卡头说明中。七日历史用日期条选择一天；无记录不解释为休息。
- 部位组数与训练间隔合并为一个概览，点击部位查看细分肌群和来源动作；旧未知性质只在统一说明中呈现。

## 记录兼容

- 山羊挺身保留原 `back_extension` ID，增加 `back_extension_hip`（臀腿侧重）。两者同日可并存；双杠臂屈伸和提踵复用已有独立 ID 组成练法选择。
- 新动作记录包含 `recordingDefaults` 和 `exerciseSnapshot`。快照保存当时名称、动作模式、主练/协同肌群及细分标签，统计和历史优先读取快照。旧记录无快照时继续读取旧 ID，不迁移、不重新归类。
- 暖身、正式和旧未分类组都可属于已记录组数；不将其统称有效组。一个部位同组去重，多部位总和不等于全身组数。协同不固定折半。
- 器械刻度、自重和辅助重量不加入公斤负荷量；这些数值继续作为原记录保留。
- 山羊挺身髋伸展练法的臀肌/腿后侧参与参考 Andersen 等（2021），DOI: 10.52082/jssm.2021.181；标签描述练法侧重，不用肌电比例折算增肌组数。
