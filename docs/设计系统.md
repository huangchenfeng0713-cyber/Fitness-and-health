# 设计系统 · B 方案试点

2026-09-08。在现有绿色强调色、浅色背景、圆角白卡及系统字体基础上收敛规则。本轮落地共享基础与健身页，其他页面按审查计划逐步采用；本文件不是所有页面已经合规的声明。

## 页面与布局

- 保留今日、饮食、数据、健身四个主栏目，设置从全局顶栏进入。
- 每页优先呈现核心任务。今日负责状态及下一步；饮食负责记录；数据负责跨日查看；健身负责安排与记组；设置负责低频配置及数据管理。
- 页面内容最大宽度沿用应用壳；手机边距 16px，卡片内边距 16px，区块间距 16px。使用 `--view-inline-pad`、`--card-pad`、`--section-gap`，不要散落新增近似值。
- 卡片高度由内容决定。摘要独立成行，主操作不与长说明争宽度。列宽按信息用途分配，窄屏换行，不强制等高等宽。
- 健身使用“本次训练 / 训练记录”局部视图。动作选择进入 sheet；训练记录和部位间隔在记录视图。当前任务页不铺满动作库和历史空卡。

## 文字、间距、颜色

沿用 `--fs-display/title/headline/value/body/footnote/caption` 字号阶梯及既有字重。正文承载动作与数值，次级文字承载日期、单位和状态；不得用小号灰字藏关键限制。

| 用途 | 规则 |
|---|---|
| 页面 / 卡片标题 | 原有字号阶梯，避免每张卡自建标题尺寸 |
| 数值 | 保留单位、日期与统计范围；有效记录和已安排数量分别命名 |
| 同一信息内部 | `--space-0/1`：2/4px |
| 控件或紧密相关内容 | `--space-2/3`：8/12px |
| 换区块 | `--space-4/5`：16/24px |
| 主操作 | `--action-fill` 与 `--on-action` 配对，独立于数据色与状态色 |
| 轻操作 / 已选 | 沿用强调色与浅色底；不能仅靠颜色表达已选，配合勾选及 ARIA 状态 |
| 相似动作 | 中性说明“模式相近”，详情点开；不作为错误或禁止添加 |
| 风险 | 只在当前条件需要时出现；保留必要健康风险说明，不用 AI、参考线或弱相关标签充当诊断 |

主按钮浅色配对为 `#087d62 / #ffffff`，深色配对为 `#2dc39a / #0d1014`。语义色、图表数据色、能量圆环颜色保持原用途，不借改主按钮之机重映射。

## 控件与共享组件

| 组件 / token | 契约 |
|---|---|
| `cardHeader` | 标题与操作同层；长摘要在下一行。当前在健身试点使用 |
| `emptyState` | 一句当前状态 + 当前可执行操作；不堆叠多个无关空状态 |
| `segmentedGroupProps / segmentedItemProps` | 互斥选择沿用既有角色；Tab 只进入当前项，方向键 / Home / End 切换并恢复焦点 |
| `containModalFocus` | 打开隔离背景；Tab 首尾循环；Escape 交由调用方；关闭恢复入口。嵌套弹层恢复原来的 inert 状态 |
| `openSheet / setSheetFooter` | 单一 sheet 实例、正文滚动、独立底栏；保留原有防幽灵点击、拖动和安全区逻辑 |
| `selectBar` | 待选摘要可展开逐项核对。保存中禁用重复提交与清空，失败保留选择；空清单收起 |
| `--touch-target` | 44px；试点文字按钮、分段控件、说明入口采用。原圆形加号保留已有扩大命中区 |

输入框保留显式标签和单位、错误定位及修复入口。键盘输入期间不得整页重建输入节点。不得以统一视觉为由更改空值语义、格式化精度或健康算法。

## 状态与交互

- **动作选择**：列表、搜索、推荐都先待选，再统一确认；点行不添加，点加号才选择。已加入动作在本次训练中管理。
- **推荐批次**：一次选择面板内的候选保持稳定。逐个选不补位；全选只选本批；确认后回到训练。再次打开是用户主动补充，已经安排的模式不自动补齐到数量上限。
- **计划 / 已记录**：动作存在不等于训练完成。沿用核心有效组规则：有效正次数或完成标记。空计划单独折叠，部位间隔沿用主练口径。
- **删除**：单项移除提供撤销；含组数的整次清空需要确认。撤销只恢复本次移除的数据，保留期间新增项；同 ID 出现新内容时拒绝覆盖。
- **替换**：有记录时明确说明旧记录会移出，新动作空组开始。成功后可撤销；新动作已有新记录时拒绝覆盖撤销。
- **反馈**：写入成功后才报成功；失败显示可操作错误并保留输入。长期解释用可访问帮助，临时操作反馈用现有 toast；不要在每行反复解释同一件事。
- **待选生命周期**：同日关闭 / 重开保留，确认成功后清除对应项，跨日清除；未写入的选择不冒充已保存数据。

## 移动端与验收

保留应用壳的安全区和固定顶底栏。sheet 安全区只在接触屏幕底部的层计算一次；底栏不得覆盖正文最后一项，展开的待选清单应可独立滚动。

320/375/390/430px 均检查主视图、展开记组、选择器、记录视图；另外检查 200% 文字。重要名称允许换行，器械筛选不能只剩省略号。触控目标与信息视觉尺寸分别处理。

自动浏览器验收不能替代 iPhone Safari / 主屏幕 PWA 的系统文字放大、软键盘、Home 指示条、横屏及 VoiceOver 测试。试点通过用户验收后，再推广到今日、饮食、数据和设置的具体布局。
